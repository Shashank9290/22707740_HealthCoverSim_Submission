# HealthCoverSim

HealthCoverSim is a full-stack private health insurance quote simulator created for Assignment 1.

The application allows users to create, calculate, save, view, edit, update and delete health insurance quotes.

## Technologies Used

- React
- JavaScript
- Node.js
- Express.js
- SQLite
- HTML
- CSS

## Project Structure

HealthCoverSim/
- client/ - React frontend
- server/ - Express backend and SQLite database
